## Field Release Notes / WhatsApp Message

*iREPS MOBILE — NEW RELEASE*  
*Release Candidate 1 (LIVE)*  
*26 August 2026*

A new version of iREPS Mobile is ready for field use.

*WHAT'S NEW*

• *Disconnection & Reconnection*  
Improved the meter Disconnection and Reconnection workflows and lifecycle handling.

• *No Access*  
No Access reasons have been standardised so that the same approved reasons are used consistently across the relevant field workflows.

• *Ward ERF Sync*  
Ward ERF Sync is available again from the Admin menu, making it easier to manage and remove locally stored Ward ERF data.

• *Meter Discovery*  
The Normalisation section has been cleaned up and simplified by removing redundant options and using the approved normalisation values.

• *TRNS*  
Improved meter identification in TRNS so that transactions belonging to the selected meter can be resolved correctly across different transaction types.

• *General Field Improvements*  
Additional refinements have been made to field forms and meter lifecycle operations to improve consistency during normal field work.

*IMPORTANT*

This APK is currently a *Release Candidate / Pilot Release*.

Please use the application normally during field operations and report any problems, including:

• Login problems  
• ERF or Ward syncing problems  
• Meter Discovery problems  
• TRN submission problems  
• Photo or media problems
