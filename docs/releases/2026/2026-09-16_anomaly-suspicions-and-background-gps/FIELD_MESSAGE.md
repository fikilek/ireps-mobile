# Field Release Message

**Release:** Meter Ok suspicions, background GPS repair
**Release Date:** 16 September 2026
**Status:** Hold until device verification passes

---

## Message for the field team

> **New iREPS update — please install**
>
> There is a new version of iREPS. Everyone must install it. Please do it before you start work.
>
> **What is new**
>
> When you choose **Meter Ok**, you can now say what kind of Ok it is. There are three choices:
>
> - **Operationally Ok** — the meter is fine, nothing suspicious. Nothing changes for you here.
> - **Bridge Suspicion** — the meter works, but you think it has been bridged.
> - **Bypass Suspicion** — the meter works, but you think it has been bypassed.
>
> If you choose one of the two suspicions, **iREPS will ask you for an anomaly photo** and will not let you submit without it. Please take a clear picture of what made you suspicious. Without the photo the suspicion cannot be proved later, and the app will not accept it.
>
> A Meter Ok with a suspicion shows in **orange** instead of green, so the office can see it straight away.
>
> **Also fixed**
>
> The app was crashing on some phones while it tracked your location in the background, and on those phones your location may not have been reaching the office at all. That has been repaired in this version. This is another reason to install it.
>
> **Please note:** this update only reaches your phone if you install it. Please confirm once you have.

---

## Notes for whoever sends this

- Send only after the device verification in `VERIFICATION.md` passes, especially the background GPS checks.
- Everyone must install. There is no automatic update for this release — that capability starts with the release **after** this one.
- Anyone who does not install keeps the single "Operationally Ok" option and cannot record a suspicion at all.
- Worth saying plainly when you send it: the photo is not bureaucracy. A bridge or bypass suspicion with no picture is not something anyone can act on.
