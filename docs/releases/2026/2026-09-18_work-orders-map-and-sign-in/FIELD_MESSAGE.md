## Notes for whoever sends this

- **Send the LIVE link only after the owner has checked the TEST build** (`VERIFICATION.md`, device checks).
- **Everyone must install.** This release is not sent over the air.
- **Install over the old app; never uninstall first.** The new APK has a higher build number and the same signing key, so it installs over build 11 and keeps the phone's waiting forms. Uninstalling deletes them.
- **Anyone who does not install** keeps build 11. It still works, but without the batch search, the map, the batch check or the clearer sign-in messages. It still lets a worker capture a meter that is already done, or work a batch that was taken away.
- **Warn workers about meter numbers.** A number typed with a dash, slash or dot is now refused. It is not a fault; they type it without the symbol.
- **Ask for one number back:** how long My Work Orders takes to open the first time each morning. That first opening is the part still to improve.
