# iREPS Release Register

This directory contains the authoritative release records for iREPS Mobile.

## Release Structure

Each released mobile version must have its own folder under:

docs/releases/YYYY/

Each release folder contains:

- RELEASE_NOTES.md
- FIELD_MESSAGE.md
- DEPLOYMENT_RECORD.md
- VERIFICATION.md
